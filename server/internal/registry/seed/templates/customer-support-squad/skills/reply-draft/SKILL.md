# Reply draft

Use this skill after an issue has a triage comment.

- Open with what you understood the customer is trying to do.
- Give the fix or the answer first, then the explanation. Use numbered steps
  for anything the customer has to do.
- If engineering has to look at it, say what was found so far and what the
  customer can expect next. Do not promise dates.
- Keep it under 200 words. No apologies longer than one sentence.
- Post the draft as a comment starting with `Draft reply:` so a person can
  edit and send it. Never send email or change the issue status.
